Xuất / nhập dự án

Sao lưu storyboard, prompt, model và trạng thái thủ công.

Xuất dự án JSON

Tải xuống dữ liệu dự án để sao lưu hoặc chuyển sang máy khác. Ảnh sẽ không được nhúng trong JSON; cần tải ảnh riêng.

Nhập dự án JSON

Khôi phục dự án từ file JSON đã xuất trước đó. Dữ liệu dự án hiện tại sẽ được thay thế.

Lưu trữ và quyền riêng tư

  • Thông tin dự án và model được lưu cục bộ trong trình duyệt (localStorage).
  • Ảnh được lưu tạm trong bộ nhớ của trang; có thể cần tải lại sau khi đóng hoặc làm mới trình duyệt.
  • Không nhập API key hoặc mật khẩu vào prototype này.
  • GitHub Pages không cung cấp backend, hàng đợi hay tự tạo video.
